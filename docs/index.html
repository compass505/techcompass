東芝や無印良品など、複数の企業で「不審なログイン画面」　各社が注意呼びかけ　「polyfill io」経由か

要約

東芝や無印良品など複数企業のサイトで、外部サービス経由で不審なログイン画面が表示される事象が確認され、各社が注意喚起。原因は外部配信のpolyfill.io経由の可能性が指摘されている。

選定理由を見る

外部JS配信を介した広範な不審画面はサプライチェーン型のセキュリティリスクで影響範囲が大きい。

要約
